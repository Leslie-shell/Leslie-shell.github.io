Redis 内存碎片化管理

Redis 内存碎片化是指已分配的内存无法被有效利用，导致内存浪费的现象。Redis 提供了多种机制来动态处理内存碎片化问题，包括监控、自动整理和手动整理，同时提供了最佳实践和注意事项。

1. 内存碎片率监控

  • 通过 INFO MEMORY 命令查看内存碎片情况：
  • 关键指标 mem_fragmentation_ratio：
    • ≈1.0 → 内存几乎没有碎片
    • 1.0 - 1.5 → 碎片率合理
    • >1.5 → 碎片较多
    • <1.0 → Redis 使用了交换空间 (swap)

CAS 与 Atomic

一、什么是 CAS

  • CAS（Compare-And-Swap）：比较并交换，是一条 CPU 并发原语，用于判断内存中某个值是否为预期值，如果是，则将其更新为新的值，该操作是原子的。
  • 操作流程：
    1. 内存中有一个变量 V，预期值为 A。
    2. 当 V 的实际值等于 A 时，将 V 更新为 B。
    3. 整个操作保证原子性。

二、CAS 基本原理

  • 在 Intel CPU 中，CAS 使用 cmpxchg 指令实现，该指令是 CPU 原语，能够保证操作的原子性。
