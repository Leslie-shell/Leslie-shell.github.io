1. 上亿用户连续登录次数（BitMap）

  • 优点：内存占用小、查询快。
  • 场景：签到、活跃统计。

2. 统计双方共同好友（集合交集）

  • 交集结果：3,4
  • 其他方案：Neo4j、HBase+Hadoop（离线计算）。

3. 上亿用户实时积分排行榜（ZSet）

  • 分桶策略：可按分数段或用户 ID 拆分多个 ZSet。

4. RDB 与 AOF

RDB 快照

  • fork 子进程写入磁盘，恢复快，可能丢数据。

AOF 日志

  • 以日志方式记录操作，数据安全，恢复慢，文件大。

7. 主从复制

  • Master 异步复制，读写分离。

9. Redis 集群方案
