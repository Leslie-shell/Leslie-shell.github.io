Spring 声明式事务原理

1. 开启事务功能

  • @EnableTransactionManagement → 激活事务注解功能
  • 注册事务增强器 TransactionalAnnotationBeanPostProcessor
  • PlatformTransactionManager 负责实际事务操作

2. 编写业务 Bean 和事务方法

  • @Transactional 声明事务
  • Spring 代理对象会在方法执行前后执行事务逻辑

3. Spring 容器启动与后置处理器注册

  • 容器启动时：
    1. 解析 @EnableTransactionManagement → 注册 TransactionalAnnotationBeanPostProcessor
    2. 后置处理器继承自 AbstractAutoProxyCreator，拦截 Bean 创建
    3. 检查 Bean 是否有 @Transactional 方法 → 如果有，创建代理对象

  • 代理对象会拦截目标方法调用，执行事务逻辑

  • 顺序：
    1. 开启事务
    2. 执行目标方法
    3. 方法正常 → 提交事务
    4. 方法异常 → 回滚事务
