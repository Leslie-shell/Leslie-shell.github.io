Spring 核心知识整理（Bean、容器、AOP 等）

1. Spring 容器中 Bean 的作用域

作用域 描述 使用场景
singleton 单例模式，整个 Spring IoC 容器中仅有一个实例 默认作用域，节省资源
prototype 原型模式，每次通过 getBean 获取都会创建新实例 需要每次请求新实例时使用
request 每次 HTTP 请求创建一个新实例 Web 应用有效
session 每个 HTTP Session 创建一个新实例 Web 应用有效
globalsession 每个全局 HTTPSession 创建新实例 PortletContext 下有效
  • 重点：
    • singleton：容器管理生命周期，可重复使用，性能优。
    • prototype：容器只负责创建，之后不再管理，销毁需依赖 GC。
    • 默认作用域是 singleton。
    • prototype 创建、销毁开销大，应尽量避免不必要使用。

2. Spring、Spring Boot、Spring Cloud 区别

  • Spring：基础框架，提供 IoC 容器、AOP、事务管理等。
  • Spring Boot：约定优于配置的快速开发框架，简化 Spring 项目启动、配置和部署。
  • Spring Cloud：分布式系统基础设施框架集合，利用 Spring Boot 风格，实现：
    • 服务发现与注册
    • 配置中心
    • 消息总线
    • 负载均衡
    • 断路器
    • 数据监控
    • 一键启动、部署分布式服务

3. @Component 与 @Bean 区别

对比 @Component @Bean
作用对象 类级别注解 方法级别注解
创建方式 自动扫描，Spring 控制实例化 编程式创建，开发者控制实例化逻辑
用途 应用自定义业务类（Service、Repository、Controller 等） 第三方库 Bean、复杂初始化逻辑、多个同类 Bean
配置方式 依赖 @ComponentScan 自动扫描 定义在 @Configuration 类中，显式配置

4. BeanFactory 与 ApplicationContext 区别

  • 关系：
    • ApplicationContext 是 BeanFactory 的子接口，扩展了更多功能。
  • BeanFactory 功能：
    • 核心：getBean
    • 默认实现：DefaultListableBeanFactory
  • ApplicationContext 功能扩展：
    • 国际化：MessageSource
    • 资源访问：ResourcePatternResolver
    • 事件发布：ApplicationEventPublisher
    • 获取环境信息：EnvironmentCapable

5. Spring AOP

  • 实现方式：
    • JDK 动态代理：接口，使用 Proxy.newProxyInstance + InvocationHandler
    • CGLIB：类，使用 Enhancer + MethodInterceptor
  • 选择规则：
    • 实现接口：默认 JDK 动态代理
    • 强制使用 CGLIB：可指定
    • 无接口：必须使用 CGLIB
  • Spring 会自动在 JDK 动态代理和 CGLIB 之间切换。

6. Spring 循环依赖解决方案

  • Spring 通过三级缓存解决循环依赖：
    1. singletonObjects：一级缓存，存放完全初始化的单例 Bean。
    2. earlySingletonObjects：二级缓存，存放提前曝光的 Bean 引用。
    3. singletonFactories：三级缓存，存放 ObjectFactory，用于创建 Bean。
  • 支持 构造器循环依赖（不支持）、属性注入循环依赖（支持）。

参考文章：https://blog.csdn.net/a745233700/article/details/110914620

7. Spring 常见后置处理器

后置处理器 作用
AutowiredAnnotationBeanPostProcessor 解析 @Autowired、@Value 注解
CommonAnnotationBeanPostProcessor 解析 @Resource、@PostConstruct、@PreDestroy 注解
ConfigurationPropertiesBindingPostProcessor 解析 @ConfigurationProperties 注解
ContextAnnotationAutowireCandidateResolver 解析注解字符串依赖
