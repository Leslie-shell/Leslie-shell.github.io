Spring 容器刷新 (refresh()) 完整流程解析

参考：Spring BeanDefinition加载流程分析

Spring 容器的 refresh() 是整个 IoC 容器初始化、Bean 创建和依赖注入的核心方法，理解它有助于掌握 Spring IoC、AOP、事件驱动和生命周期管理。

1. prepareRefresh() 刷新前的准备工作

  1. 初始化属性源：
  • AbstractApplicationContext 中实现为空，子类可自定义属性初始化。
  1. 验证环境属性：
  • 检查容器配置的必需属性是否合法。
  1. 保存早期事件监听器：
  • 保存容器启动前注册的 ApplicationListener。

2. 获取 BeanFactory

  • 内部实现：
  • 创建 BeanFactory 并返回，为后续 Bean 注册和创建做准备。

3. prepareBeanFactory(beanFactory) BeanFactory 预准备

  • 设置类加载器，支持表达式解析。
  • 添加基础 BeanPostProcessor：
    • ApplicationContextAwareProcessor → 处理 xxxAware 接口注入
  • 忽略自动装配接口：
    • EnvironmentAware, EmbeddedValueResolverAware 等
  • 注册可自动装配组件：
    • BeanFactory、ResourceLoader、ApplicationEventPublisher
  • 添加 ApplicationListenerDetector → 检测 Bean 是否实现 ApplicationListener
  • 注册编译时 AspectJ 组件
  • 注册容器基础组件：
    • Environment、systemProperties、systemEnvironment

  • 子类可覆盖该方法，在 BeanFactory 准备完成后进行进一步定制。
  • 常用于自定义 Bean 定义或修改现有 Bean 属性。

6. 注册 Bean 后置处理器

  • 后置处理器类型：
    • DestructionAwareBeanPostProcessor
    • InstantiationAwareBeanPostProcessor
    • SmartInstantiationAwareBeanPostProcessor
    • MergedBeanDefinitionPostProcessor（internalPostProcessors Map）
  • 注册顺序：
    1. PriorityOrdered BeanPostProcessor

    3. 无优先级接口 BeanPostProcessor
    4. MergedBeanDefinitionPostProcessor
    5. 注册 ApplicationListenerDetector → 检测 Bean 是否实现 ApplicationListener

7. 初始化国际化组件 MessageSource

  • 获取容器中 ID 为 messageSource 的 Bean
  • 若不存在，创建 DelegatingMessageSource
  • 用于国际化消息解析（根据地区信息获取文本）

8. 初始化事件派发器 ApplicationEventMulticaster

  • 获取 BeanFactory 中 ApplicationEventMulticaster Bean
  • 若未配置，创建 SimpleApplicationEventMulticaster
  • 注册到 BeanFactory，支持事件驱动模型

13. 总结

  1. BeanDefinition 保存与管理
    • 注解 Bean：@Service、@Component、@Bean
    • XML Bean：<bean>
      → 保存到 DefaultListableBeanFactory 的 BeanDefinitionMap
  2. Bean 创建时机
    • 按需创建：getBean()
    • 批量创建：finishBeanFactoryInitialization()
  3. Bean 后置处理器
    • 功能增强 Bean：
      • 自动注入：AutowiredAnnotationBeanPostProcessor
      • AOP 功能：AnnotationAwareAspectJAutoProxyCreator
      • 异步：AsyncAnnotationBeanPostProcessor
  4. 事件驱动模型
    • 事件监听器：ApplicationListener
    • 事件派发器：ApplicationEventMulticaster
  5. LifecycleProcessor
    • 管理容器和 Bean 生命周期回调
    • Spring Boot 通过 LifecycleAutoConfiguration 提前注册 Lifecycle Bean
