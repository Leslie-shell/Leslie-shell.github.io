Spring AOP 原理笔记

1. 什么是 AOP？

  • AOP（面向切面编程）：在不修改业务逻辑的前提下，给方法增加额外功能（如日志、事务、安全检查）。
  • 核心思想：
    • 业务逻辑保持纯粹
    • 通知（Advice）和切面（Aspect）独立
    • 通过代理对象在方法执行前后执行通知

2. 开启 AOP 功能

  • 作用：
    1. 开启 Spring AOP 功能
    2. 注册 AnnotationAwareAspectJAutoProxyCreator（Bean 后置处理器）

3. Spring 注册 AnnotationAwareAspectJAutoProxyCreator

3.2 注册器 AspectJAutoProxyRegistrar

3.3 工具类注册逻辑

  • 解释：
    • 容器启动时，调用 AspectJAutoProxyRegistrar → 注册 AnnotationAwareAspectJAutoProxyCreator
    • 名称固定：internalAutoProxyCreator
    • 作用：拦截后续所有 Bean 的创建过程，判断是否需要生成代理对象，实现 AOP

4. Bean 创建流程与 AOP 结合

4.1 容器初始化

  • 流程：
    1. 注册所有 Bean 后置处理器（包括 AnnotationAwareAspectJAutoProxyCreator）
    2. 创建单例 Bean（getBean() 或 doCreateBean()）
    3. 后置处理器拦截 Bean 创建：
      • postProcessBeforeInstantiation()（创建前可返回代理）
      • postProcessAfterInitialization()（创建后可包装代理）

7. 总结

  1. 容器启动 → 解析配置类 → @EnableAspectJAutoProxy
  2. 注册后置处理器 → AspectJAutoProxyRegistrar → AnnotationAwareAspectJAutoProxyCreator
  3. 创建 Bean → 后置处理器拦截 → 判断是否增强 → 创建代理对象
  4. 调用方法 → 代理对象 → 拦截器链 → 通知方法 → 目标方法
  5. 核心概念：
    • Advice：通知方法（Before、After、Around）
    • Aspect：切面类
    • Advisor：封装 Advice + Pointcut
    • Proxy：代理对象，触发增强链执行
