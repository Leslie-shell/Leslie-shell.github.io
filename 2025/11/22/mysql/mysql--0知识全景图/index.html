11. MySQL 底层实现

事务日志

  • redo log：保证事务持久化
  • undo log：事务回滚

锁与事务

  • InnoDB 支持行锁、gap锁、next-key 锁
  • 事务隔离级别：
    • READ UNCOMMITTED / READ COMMITTED / REPEATABLE READ / SERIALIZABLE

MVCC

  • 保证事务原子性
  • undo log + read_view
  • 不同隔离级别生成 read_view 的规则
  • InnoDB MVCC vs 理想 MVCC 区别

InnoDB 锁分类

  • record lock（行锁）
  • gap lock（间隙锁）
  • next-key lock（行+间隙锁）

binlog 与 redo log 区别

  • binlog：记录逻辑操作，用于复制与恢复
  • redo log：记录物理页修改，用于崩溃恢复

12. InnoDB 与 MyISAM 区别

详见：InnoDB vs MyISAM

  • InnoDB 支持事务、行锁、外键
  • MyISAM 不支持事务，表锁

13. COUNT 区别

  • COUNT(1)、COUNT(*)、COUNT(column)
    参考：COUNT执行区别

14. 主键与唯一索引区别

  1. 主键必创建唯一索引，但唯一索引不一定是主键
  2. 主键不允许 NULL，唯一索引可允许 NULL
  3. 表只能有一个主键，可有多个唯一索引
  4. 主键可被外键引用，唯一索引不可
  5. 主键是一种约束，唯一索引是一种索引
