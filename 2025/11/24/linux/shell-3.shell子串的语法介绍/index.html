3. 前缀 / 后缀删除（去掉）

“去”就是 删除匹配部分，剩下未匹配的部分就是结果。

操作 符号 含义
去最短前缀 # 从开头删除 最短匹配 的模式
去最长前缀 ## 从开头删除 最长匹配 的模式
去最短后缀 % 从末尾删除 最短匹配 的模式
去最长后缀 %% 从末尾删除 最长匹配 的模式

示例

4. 字符串替换

操作 语法 说明
替换第一次出现 ${变量/旧/新} 替换第一个匹配
替换所有匹配 ${变量//旧/新} 替换全部匹配
开头匹配替换 ${变量/#旧/新} 仅开头匹配时替换
结尾匹配替换 ${变量/%旧/新} 仅结尾匹配时替换

8. 速查表

功能 语法 示例
提取子串 ${var:start:length} ${str:0:5}
去最短前缀 ${var#pattern} ${file#*.}
去最长前缀 ${var##pattern} ${file##*.}
去最短后缀 ${var%pattern} ${file%.gz}
去最长后缀 ${var%%pattern} ${file%%.*}
单次替换 ${var/old/new} ${text/apple/orange}
全部替换 ${var//old/new} ${text//apple/orange}
开头替换 ${var/#old/new} ${str/#file/newfile}
结尾替换 ${var/%old/new} ${str/%.txt/.md}
保留数字 ${var//[!0-9]/} 123456
删除数字 ${var//[0-9]/} abcdef
包含判断 [[ $var == *substr* ]] if [[ $str == *World* ]]
开头/结尾判断 [[ $var == pattern* ]] if [[ $str == Hello* ]]
