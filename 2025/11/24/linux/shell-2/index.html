二、系统环境变量查看与操作命令区别

命令 功能 作用与区别
set 列出当前 shell 的所有变量和函数 包含未导出的局部变量和 shell 函数，信息最全，但输出杂乱，主要用于调试当前 shell 状态
env 显示环境变量 仅显示已导出的变量，子 shell 可继承，适合查看系统环境变量及传递给程序的变量
declare 查看变量类型、属性、函数 可用于区分普通变量、数组、只读变量以及函数，支持 -p 查看值，适合脚本中精细管理变量
export 设置或查看导出变量 将变量导出到环境，使其对子 shell可见，可在命令中直接查看或设置导出变量

示例

总结区别:

  • set 最全，包含函数和局部变量
  • env 只显示导出变量
  • declare 用于查看类型和属性，适合调试和脚本控制
  • export 用于导出变量或显示导出状态
