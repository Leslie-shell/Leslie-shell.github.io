Shell 变量定义

定义与使用

变量规则

  • 只能包含字母、数字、下划线
  • 不能以数字开头
  • 区分大小写
  • 双引号可防止空格截断：echo "$path"

作用范围

类型 用法 说明
局部变量 var="a" 当前 shell 有效
环境变量 export var="a" 子进程可继承
只读变量 readonly var="a" 不可修改

特殊变量

变量 含义
$0 脚本名
$1~$9 参数
$# 参数个数
$@ 或 $* 所有参数
不同点：只有在双引号中体现出来。假设在脚本运行时写了三个参数 1、2、3，则 “ * “ 等价于 “1 2 3”（传递了一个参数），而 “@” 等价于 “1” “2” “3”（传递了三个参数）。
$? 上一命令状态
$$ 当前进程ID

比较运算符（Comparison Operators）

注意：整数比较 和 字符串比较 写法不同！

数值比较（整数）

符号 含义 示例
-eq 等于 [ $a -eq $b ]
-ne 不等于 [ $a -ne $b ]
-gt 大于 [ $a -gt $b ]
-lt 小于 [ $a -lt $b ]
-ge 大于等于 [ $a -ge $b ]
-le 小于等于 [ $a -le $b ]

字符串比较

符号 含义 示例
= 等于 [ "$a" = "$b" ]
!= 不等于 [ "$a" != "$b" ]
-z 长度为 0 [ -z "$a" ]
-n 长度不为 0 [ -n "$a" ]

逻辑运算符（Logical Operators）

符号 含义 示例
&& 逻辑与 [ $a -gt 0 ] && [ $b -gt 0 ]
! 逻辑非 [ ! -z "$a" ]

文件测试运算符（File Test Operators）

运算 含义 示例
-e 文件存在 [ -e file ]
-f 普通文件 [ -f file ]
-d 目录 [ -d dir ]
-r 可读 [ -r file ]
-w 可写 [ -w file ]
-x 可执行 [ -x file ]
