MySQL 函数（Function）

1.1 定义

函数就是一个可以返回单个值的 SQL 代码块。
它可以接收参数，做计算或处理，然后返回一个结果。

  • 特点
    • 必须有返回值（RETURN）
    • 可在 SELECT、WHERE、INSERT 等语句中使用
    • 一般用于封装计算或重复逻辑

1.2 语法

  • DETERMINISTIC：相同输入是否总返回相同结果
  • READS SQL DATA：函数内是否读取数据
  • MODIFIES SQL DATA：是否修改数据（一般不推荐在函数里修改表）

MySQL 存储过程（Stored Procedure）

2.1 定义

存储过程是一个可以执行一系列 SQL 语句的程序块。
可以包含条件判断、循环、游标操作等，支持输入/输出参数。

  • 特点
    • 可以有多个输入（IN）、输出（OUT）或输入输出（INOUT）参数
    • 不能直接在 SELECT 里使用（调用用 CALL）
    • 适合复杂操作、事务、批量处理

2.2 语法

  • 参数类型：
    • IN：输入参数
    • OUT：输出参数
    • INOUT：输入输出参数

函数 vs 存储过程对比

特性 函数 (Function) 存储过程 (Procedure)
返回值 必须返回单值 可无返回值（可有 OUT 参数）
调用方式 SELECT / SQL 表达式中 CALL 存储过程名()
可否修改表 不推荐 可以修改表、做事务
适用场景 单值计算、封装逻辑 批量操作、事务、复杂流程

常用场景示例

  • 函数：
    • 计算折扣金额 calc_discount(price, rate)
    • 转换格式 format_date(date, '%Y-%m')
    • 分级或评级 grade(score)
  • 存储过程：
    • 批量更新工资或利息
    • 批量生成报表
    • 多步骤事务（插入、更新、记录日志）
