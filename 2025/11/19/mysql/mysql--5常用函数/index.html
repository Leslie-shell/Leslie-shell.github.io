mysql常用函数

发表于 2025-11-19 更新于 2025-11-29 分类于 Mysql 阅读次数：
本文字数： 5.4k 阅读时长 ≈ 5 分钟

一、空值与条件处理（NULL / 条件）

IF(expr, true_val, false_val) — 三元判断

IFNULL(expr, alt) — expr 为 NULL 则用 alt

COALESCE(expr1, expr2, ...) — 返回第一个非 NULL 值

NULLIF(a, b) — 若 a = b 返回 NULL，否则返回 a

CASE ... WHEN ... THEN ... END — 多分支条件

二、字符串函数（String）

CONCAT(a,b,...) — 拼接

CONCAT_WS(sep, a, b, ...) — 带分隔符拼接（跳过 NULL）

SUBSTRING(str, pos, len) / SUBSTR — 截取

LEFT(str, n) / RIGHT(str, n) — 左/右取 n 字符

LENGTH(str) — 字节长度；CHAR_LENGTH(str) — 字符长度

INSTR(str, substr) / LOCATE(substr, str) — 查子串位置（>0 表示存在）

REPLACE(str, from, to) — 替换子串

TRIM(str) / LTRIM / RTRIM — 去空白

LPAD(str, len, pad) / RPAD — 左右补齐

LOWER(str) / UPPER(str) — 大小写转换

FORMAT(number, d) — 格式化数字（千分位、指定位小数）

FIND_IN_SET(str, strlist) — 在逗号分隔列表中查找（常用于 set-like）

FIELD(val, val1, val2, ...) — 自定义顺序排序/匹配索引（返回位置）

REGEXP / RLIKE — 正则匹配（不是函数但常用）

三、数值函数（Numeric）

ABS(x) — 绝对值

ROUND(x, d) / TRUNCATE(x, d) — 四舍五入 / 截断

CEIL(x) / FLOOR(x) — 向上/向下取整

MOD(a, b) — 取模（余数）

POWER(x, y) — 幂

RAND() — 随机数（0~1）

四、日期时间函数（Date & Time）

NOW() / CURRENT_TIMESTAMP() — 当前时间

CURDATE() / CURTIME() — 当前日期 / 时间

DATE(expr) — 取日期部分（去掉时分秒）

DATE_FORMAT(date, fmt) — 按格式输出

STR_TO_DATE(str, fmt) — 字符串转日期

DATE_ADD(date, INTERVAL n unit) / DATE_SUB — 日期加减

DATEDIFF(a, b) — 天数差（a - b）

TIMESTAMPDIFF(unit, a, b) — 指定单位差值（YEAR, MONTH, DAY, HOUR…）

UNIX_TIMESTAMP() / FROM_UNIXTIME() — 时间戳互转

五、聚合函数（Aggregate）

COUNT(*) / COUNT(col) — 计数

SUM(col) / AVG(col) / MIN / MAX — 求和/平均/最小/最大

GROUP_CONCAT(expr [ORDER BY ... SEPARATOR ',']) — 分组拼接

六、JSON（MySQL 5.7+）

JSON_EXTRACT(json, path) 或 col->'$.a.b' — 取值

JSON_SET(json, path, val) / JSON_REPLACE / JSON_INSERT — 修改或插入

JSON_CONTAINS(json, val [, path]) — 判断包含关系

JSON_ARRAY() / JSON_OBJECT() / JSON_LENGTH() — 构造与长度

七、类型转换（CAST / CONVERT）

CAST(expr AS type) / CONVERT(expr, type) — 强制类型转换

八、加密 / 编码 / UUID

MD5(str) / SHA1(str) — 单向哈希

HEX(str) / UNHEX(str) — 十六进制编码/解码

UUID() / UUID_SHORT() — 唯一 ID

九、窗口函数（MySQL 8.0+）

常用模式：OVER(PARTITION BY ... ORDER BY ...)

ROW_NUMBER() — 行号

RANK() / DENSE_RANK() — 排名（并列）

SUM(...) OVER(...) / AVG(...) OVER(...) — 滚动/累计

LAG(col, offset, default) / LEAD(...) — 前/后行值

示例 2：将 NULL 或 空串统一成默认值
