mysql最常用函数合集

发表于 2025-11-19 更新于 2025-11-29 分类于 Mysql 阅读次数：
本文字数： 2.5k 阅读时长 ≈ 2 分钟

MySQL 最常用 Top 30 函数（含例子）

1. IFNULL(expr, alt) — NULL 替代（最常用之一）

2. COALESCE(a, b, c...) — 多字段取第一个非 NULL

3. NULLIF(a, b) — a=b 则 NULL

4. IF(expr, true_val, false_val) — 条件判断

5. CASE WHEN — 多分支判断（业务最常用）

6. CONCAT(a,b) — 字符串拼接

7. CONCAT_WS(sep,a,b) — 忽略 NULL 的拼接

8. REPLACE(str, from, to) — 替换

9. LEFT(str,n) / RIGHT(str,n) — 左右截

10. SUBSTRING(str, pos, len) — 中间截

11. INSTR(str, substr) — 判断是否包含（比 LIKE 快）

12. LENGTH(str) / CHAR_LENGTH(str)

13. TRIM() — 去空格

14. LPAD() / RPAD() — 左右补齐

15. NOW() — 当前时间

16. CURDATE() / CURTIME()

17. DATE_FORMAT(date, fmt) — 返回格式化日期（销量统计必用）

18. STR_TO_DATE(str, fmt) — 字符串转日期

19. DATE_ADD() / DATE_SUB() — 加天、加年等日期运算

20. DATEDIFF(a,b) — 天数差

21. TIMESTAMPDIFF(unit,a,b) — 年/月/日差值（业务必用）

22. COUNT(*) — 计数（最常用聚合）

23. SUM() / AVG() / MIN() / MAX()

24. GROUP_CONCAT() — 分组拼接列表

25. ROUND(x,d) — 四舍五入

26. FLOOR() / CEIL() — 向下/向上取整

27. MOD(a,b) — 取余

28. RAND() — 随机数

29. JSON_EXTRACT() / -> — JSON 取值

30. CAST(expr AS type) — 类型转换

✔ 额外：窗口函数（8.0+ 最常用的 3 个）

真正在业务里最常写的只有三个：

① ROW_NUMBER() — 排名（不重复）

② RANK() — 并列排名

③ LAG() — 上一行值（做环比最常用）
