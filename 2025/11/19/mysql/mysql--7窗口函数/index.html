mysql窗口函数

什么是窗口函数？

一句话：

窗口函数 = 在不分组的情况下，对某一范围（窗口）内的多行数据做计算，并把结果“附加”到每一行上。

它不会把多行合并为一行（不像 GROUP BY）。
它只是“看一下周围的行”，然后计算。

为什么需要窗口函数？（直觉理解）

假设你有工资表：

id name dept salary
1 张三 A 8000
2 李四 A 9000
3 王五 A 10000

你想：

  • 找出每个人的部门排名？
  • 每个人薪资占部门总薪资的百分比？
  • 每个人比上一个月多赚多少？

用 GROUP BY 做不到（因为 GROUP BY 会变成 1 行）。
用子查询也能做，但很难写、效率低。
窗口函数一条语句就搞定。

窗口函数的组成

格式：

可以理解为：

  • PARTITION BY = 类似 GROUP BY（按什么分组）
  • ORDER BY = 在分组内排序
  • OVER() = 对窗口内的数据做计算，不合并行

常见窗口函数 + 最通俗例子

1. 排名函数：ROW_NUMBER / RANK / DENSE_RANK

例子：部门内按工资排名

区别：

函数 是否有并列 后续名次跳不跳
ROW_NUMBER 不允许并列 不跳号
RANK 允许并列 会跳号
DENSE_RANK 允许并列 不跳号

2. 累积值：SUM / AVG / COUNT（作为窗口函数使用）

例子：计算销售的“累计销售额”

结果示意：

name sale cum_amount
A 100 100
B 200 300
C 150 450

3. LAG / LEAD（取上一行 or 下一行）

例子：算每个月的销售增长

效果：

月份 销售额 比上月多
1 100 null
2 150 50
3 120 -30

4. FIRST_VALUE / LAST_VALUE

例子：取每个部门最高工资（但每行都显示）

为什么窗口函数这么强？

✔ 不会减少行数

不像 GROUP BY。

✔ 可以对“当前行附近的数据”做任何分析

排名、累积、同比、环比，全能。

✔ 代码更易读，不用嵌套子查询

把 GROUP BY 和 窗口函数 对比理解

❌ GROUP BY（按部门求平均工资）

只有每个部门 1 行。

✔ 窗口函数（每个人都显示部门平均工资）

你的输出是：

name dept salary dept_avg_salary

而非 3 行。

最常用

部门排名

累积计算

同比/环比

部门总数或总和

部门平均
