C 调 10 孔布鲁斯口琴孔位与和弦表

孔位、吹吸气音与对应和弦

孔位 吹气音 (Blow) 吹气和弦 吸气音 (Draw) 吸气和弦
1 C C D G
2 E C G G
3 G C B G
4 C C D G7
5 E C F G7
6 G C A G9
7 C C D G9
8 E C F G9
9 G C A —
10 C C D —

注：空格“—”表示该孔吸气未形成常用和弦。

常用和弦孔位组合

和弦 常用孔位 组成音
C（I） 吹 1–3 / 1–4 C E G
G（V） 吸 1–3 / 1–4 G B D
G7（V7） 吸 2–5 G B D F
G9（V9） 吸 1–6 G B D F A
Dm（ii） 吸 4–6 D F A

使用

  1. 吹气 → 主要演奏 C 大调（I 和弦）
  2. 吸气 → 主要演奏 G 和弦（V 和弦）及延伸和弦
  3. 示例：
    • 要演奏 C 和弦 → 吹 1–3 或 1–4 孔
    • 要演奏 G 和弦 → 吸 1–3 或 1–4 孔
    • 要演奏 G7 → 吸 2–5 孔
    • 要演奏 Dm → 吸 4–6 孔
