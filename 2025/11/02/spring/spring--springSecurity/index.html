1. 核心概念

  1. Authentication（认证）
    验证用户身份，例如用户名和密码是否正确。
  2. Authorization（授权）
    确定已认证用户是否有访问特定资源的权限。
  3. Principal（主体）
    当前登录的用户对象，一般为 UserDetails。
  4. GrantedAuthority
    用户的角色或权限，例如 ROLE_ADMIN。
  5. SecurityContext / SecurityContextHolder
    保存当前用户认证信息的上下文。

13. 核心注意点

  1. 密码加密必须使用 PasswordEncoder，明文存储不安全
  2. 权限前缀：Spring Security 角色默认 ROLE_ 前缀
  3. 开发环境可以关闭 CSRF，生产环境必须开启
  4. 方法级安全需要加 @EnableMethodSecurity
  5. JWT 认证适合无状态 REST API
  6. 过滤器链顺序很重要，认证/授权顺序影响安全逻辑
