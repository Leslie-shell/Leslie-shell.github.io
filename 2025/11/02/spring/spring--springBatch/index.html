1. Spring Boot 3.x 变化

  • 不再推荐使用 @EnableBatchProcessing 注解。
  • 需要手动声明 Bean：JobRepository、JobLauncher、TransactionManager。
  • JobBuilderFactory 与 StepBuilderFactory 已弃用，推荐使用 JobBuilder 和 StepBuilder。

2. Spring Batch 简介

  • 批处理（Batch Processing）：处理大量数据分批操作
  • 常见场景：
    • 银行对账
    • 跨系统数据同步
    • 批量导入导出、报表生成

3. 核心架构

  • JobLauncher：启动 Job
  • Job：作业逻辑，可包含多个 Step
  • Step：最小执行单元
  • ItemReader / ItemProcessor / ItemWriter：读 → 处理 → 写
  • JobRepository：持久化作业信息
