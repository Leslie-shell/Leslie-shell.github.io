Shell 数学运算与条件判断整理

1. Shell 中的数学运算

1.1 算术扩展 $(( ))

  • 作用：获取整数运算结果
  • 特点：
    • 返回运算结果，可赋值或嵌入字符串
    • 变量前必须加 $
    • 只支持整数运算

示例：

  • 支持运算符：
运算 示例
加 $((a + b))
减 $((a - b))
乘 $((a * b))
除 $((a / b))
取模 $((a % b))
指数 $((a ** b))

1.2 双小括号 (( ))

  • 作用：算术运算 + 条件判断
  • 特点：
    • 不需要 $ 前缀引用变量
    • 可直接修改变量（自增/自减）
    • 返回值为 条件真假（0 为真，非 0 为假），可用于 if / while

示例：

  • 性能优势：内置命令，不 fork 外部进程

1.3 注意事项

  • $(( )) → 获取值
  • (( )) → 条件判断或直接修改变量
  • 都只支持整数运算，浮点需 bc 或 awk

2. 条件判断 [ ] 和 [[ ]]

2.1 [ ]（传统 test）

  • 作用：条件测试（整数/字符串/文件）
  • 特点：
    • 兼容性好
    • 变量前必须加 $
    • 语法严格，空格必须注意

示例：

2.2 [[ ]]（扩展 test，Bash/Zsh）

  • 作用：条件测试的扩展
  • 特点：
    • 支持逻辑运算 && / ||
    • 支持模式匹配 == / =~
    • 不会进行字段分割或通配符扩展
    • 变量前仍需 $

3. $(( )) / (( )) 与 [ ] / [[ ]] 对比表

语法 用途 变量前缀 返回值 支持类型 说明
$((expression)) 获取算术结果 需要 $ 计算结果 整数 可赋值或嵌入字符串
((expression)) 算术运算 + 条件判断 不需要 $ 0/1（真/假） 整数 常用于 if/while/for，自增自减
[ expression ] 条件测试 需要 $ 0/1（真/假） 字符串/整数/文件 传统 test，兼容性好
[[ expression ]] 扩展条件测试 需要 $ 0/1（真/假） 字符串/整数/模式匹配 Bash/Zsh 扩展，支持逻辑运算、模式匹配、正则
