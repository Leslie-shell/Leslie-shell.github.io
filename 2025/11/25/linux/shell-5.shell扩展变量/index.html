七、带 : 与不带 : 的区别

关键点：

带 : → 未定义 或 空 都视为 “无值”
不带 : → 仅未定义视为 “无值”

示例：

解释：

  • :- 把空字符串当作未设置
  • - 认为变量已定义，只是内容为空

适用于其他运算：:=、:?、:+

八、完整对照表

写法 未定义 空字符串 有值 是否赋值
${var} 空 空 value 否
${var-word} word 空 value 否
${var:-word} word word value 否
${var=word} word 空 value 是
${var:=word} word word value 是
${var?word} word(报错) 空 value 否
${var:?word} word(报错) word(报错) value 否
${var+word} 空 word word 否
${var:+word} 空 空 word 否
