Shell 内置命令和外置命令 的区别、机制、使用场景和示例

一、定义

1. 内置命令（builtin command）

  • 解释：由 Shell 自己实现并直接在 Shell 进程中执行的命令
  • 执行方式：不启动新进程
  • 作用：直接修改 Shell 的环境或状态
  • 性能：最快，开销最小
  • 特点：
    • 可以修改父 Shell 的环境（如 cd、export、readonly）
    • 无需查找 PATH
    • 脚本效率高

示例：

命令 功能
cd 切换工作目录
export 设置环境变量
alias 定义命令别名
unset 删除变量
readonly 声明只读变量
builtin 强制调用内置命令

可以用命令查看是否为内置：

2. 外置命令（external command）

  • 解释：位于文件系统中的可执行文件，Shell 需要 fork 一个新进程来执行
  • 执行方式：启动子进程
  • 作用：无法直接修改父 Shell 的环境（cd、export 等不起作用）
  • 性能：启动新进程开销大，尤其在循环中频繁调用
  • 特点：
    • 可以是二进制程序或脚本（如 /bin/ls, /usr/bin/grep）
    • Shell 通过 PATH 查找命令
    • 跨 Shell 可用

示例：

命令 功能
ls 列出目录
grep 文本搜索
awk 文本处理
sed 流编辑
cat 文件显示

二、内置命令 vs 外置命令 对比表

特性 内置命令 外置命令
执行位置 Shell 内部 子进程
是否能修改父 Shell 环境 可以 不可以
启动开销 无 有 fork/exec 开销
是否需要 PATH 不需要 需要
性能 高 相对低
可用性 仅在该 Shell 跨 Shell
查看方式 type cmd → builtin type cmd → /bin/cmd
典型示例 cd, export, alias, unset ls, grep, awk, sed

三、注意点

  1. 同名命令冲突
  1. 子 Shell 中的环境修改
  • 内置命令可以修改父 Shell 环境（除非在子 Shell 中）
  • 外置命令无法影响父 Shell
  1. 循环和性能

四、如何判断某命令是内置还是外置？

  • type cmd：显示类型
  • command -V cmd：更详细
  • which cmd：查 PATH 中可执行文件（外置）

五、总结

  1. 内置命令：Shell 内部实现，执行快，可修改父 Shell 环境
  2. 外置命令：独立可执行文件，需要 fork，不能修改父 Shell 环境
  3. 选择原则：
    • 对环境修改：必须用内置（cd, export）
    • 对文本处理：用外置（awk, sed, grep）
    • 循环或性能敏感场景：优先内置命令
