Shell 脚本核心知识整理

1. Shell 执行多行命令

1.1 命令分隔符

  • ; 用于在同一行顺序执行多条命令
  • 每条命令依次执行，不管前一条命令是否成功

1.2 条件执行

  • &&：前一条命令成功（返回 0）才执行下一条
  • ||：前一条命令失败（非 0）才执行下一条

2.2 转义字符

  • \n 换行
  • \t 制表符
  • \\ 反斜杠
  • \" 双引号

2.3 单引号 vs 双引号

  • 单引号 ' '：原样输出，变量不替换
  • 双引号 " "：允许变量替换和转义

4. source 与 ./ 执行脚本

执行方式 作用
source script.sh 或 . script.sh 在当前 shell 环境中执行，变量和修改保持在当前 shell
bash script.sh 或 sh script.sh 在子 shell 中执行，变量和修改不会影响父 shell

5. Linux Shell 变量的替换与引用

5.1 ${} 语法

  • 提供变量替换、默认值、子串截取、长度等功能

5.2 $() 命令替换

  • 执行命令并将输出作为值
  • 等价于旧式 command，但可嵌套，更安全

6. 总结要点

  1. ; 分隔顺序执行，&&/|| 条件执行
  2. echo 配合 -e 支持转义，单/双引号影响变量替换
  3. Shell 变量可读写、删除、设置默认值
  4. source 在当前环境执行，bash ./script.sh 在子 shell 执行
  5. ${} 提供强大的变量操作功能，$() 实现命令替换
