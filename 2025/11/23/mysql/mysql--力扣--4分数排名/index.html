  • 分数应按从高到低排列。
  • 如果两个分数相等，那么两个分数的排名应该相同。
  • 在排名相同的分数后，排名数应该是下一个连续的整数。换句话说，排名之间不应该有空缺的数字。

MySQL 四大窗口函数详解

MySQL 从 8.0 开始支持窗口函数（Window Functions），它们可以对查询结果集的某个窗口（即行的子集）执行计算，而不需要分组，常用于排名、累计和滑动计算等场景。

ROW_NUMBER()

功能：为结果集的每一行分配唯一的序号，从 1 开始。
特点：同一分组内不会有重复序号。

语法：

示例：

解析：

  • PARTITION BY：按班级分组，每个班级的排名从 1 开始。
  • ORDER BY：按分数降序排列。
  • 特点：行号唯一，即使分数相同，排名也不同。

RANK()

功能：按指定顺序为行生成排名，同分值会相同。
特点：出现并列排名时，会跳过后续排名。

语法：

示例：

解析：

  • 同分学生会有相同排名。
  • 如果两个学生并列第一，则下一名是第三名。
  • 用于考试或评分系统，需要体现并列名次。

DENSE_RANK()

功能：和 RANK() 类似，但不会跳过排名。
特点：并列排名后，下一名紧接着。

语法：

示例：

解析：

  • 如果两个学生并列第一，下一名就是第二名。
  • 用于需要连续名次的场景，比如奖学金名额排序。

NTILE(n)

功能：将结果集分为 n 个桶（bucket），为每行分配一个桶编号。
特点：用于分位或分组，比如四分位、百分位。

语法：

示例：

解析：

  • 将所有行按分数从高到低分成 4 个组（四分位）。
  • 每个分位内的行数量尽量均衡。
  • 常用于分析、评级、分组统计。

总结对比

函数 并列处理 是否连续 典型用途
ROW_NUMBER 无并列，唯一序号 是 唯一排序，分页、行号
RANK 并列相同排名 否 排名，体现并列的跳号
DENSE_RANK 并列相同排名 是 排名，需要连续编号
NTILE(n) 分桶，不考虑并列 是 分位分析、均分组

使用场景总结

  1. ROW_NUMBER → 分页、序号、唯一标识每行
  2. RANK → 排名，允许并列，反映名次跳号
  3. DENSE_RANK → 连续排名，奖学金/评分排名
  4. NTILE(n) → 分位分析，如四分位、五分位、评分等级
