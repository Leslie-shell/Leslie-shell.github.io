官网和其他解法

“分组连续相同数字” 的经典解法，思路是通过 行号差分法（Row Number Gap Method） 来找连续出现的数字段。

内层子查询

  • ROW_NUMBER() OVER (PARTITION BY num ORDER BY id)

    • 给每个 相同 num 的行单独编号，按 id 排序

    • 示例（针对 num=1 的行）：

      id num rn
      1 1 1
      2 1 2
      3 1 3
      5 1 4

  • ROW_NUMBER() OVER (ORDER BY id)

    • 给 所有行 按 id 排序编号

    • 示例（全局行号）：

      id num global_rn
      1 1 1
      2 1 2
      3 1 3
      4 2 4
      5 1 5
      6 2 6
      7 2 7

差值 (global_rn - rn) 的含义

  • 对同一个 num，如果是 连续的行，global_rn - rn 的值是固定的。
  • 举例：num=1 的连续段：
id num rn global_rn global_rn - rn
1 1 1 1 0
2 1 2 2 0
3 1 3 3 0
5 1 4 5 1
  • 解释：
    • 前三行连续出现 1 → 差值都是 0 → 同一组
    • 第五行的差值是 1 → 新的一组（中间被 2 打断）

总结

  • 行号差分法非常适合处理 连续重复元素的问题
  • 思路：
    1. 给每个 num 单独编号 (rn)
    2. 给全局行编号 (global_rn)
    3. 连续段差值 global_rn - rn 固定
    4. 按段分组统计，过滤出长度 >=3 的段
