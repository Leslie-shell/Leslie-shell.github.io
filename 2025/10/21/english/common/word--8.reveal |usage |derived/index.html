reveal /rɪˈviːl/

v — to make something known that was previously secret or unknown
中文释义: 揭示；透露；显示。

Examples:

  • The study reveals new insights about climate change.
  • She revealed the truth about her past.

Common Phrases

  • reveal a secret — 透露秘密
    • He refused to reveal the secret.
  • reveal the truth — 揭示真相
    • The investigation revealed the truth.
  • self-reveal — 自我揭示
    • The diary reveals the author’s feelings.

Synonyms

  • disclose
  • uncover
  • expose

Word Root

  • Root: vel- (Latin: “to cover”) → 与隐藏、覆盖相关
  • Prefix: re- 表示“回、重新、向后”
  • Formation: re + veal → reveal
  • Related Words:
    • convey — 传达
    • veil — 面纱，遮蔽
    • unveil — 揭幕，公开

usage /ˈjuːɪdʒ/

n — the way in which something is used; practice or custom
中文释义: 使用；用法；习惯。

Examples:

  • The usage of this word has changed over time.
  • Proper usage of tools improves efficiency.

Common Phrases

  • language usage — 语言使用
    • Correct language usage is important in writing.
  • word usage — 单词用法
    • The dictionary explains word usage clearly.
  • daily usage — 日常使用
    • The device is suitable for daily usage.

Synonyms

  • application
  • practice
  • utilization

Word Root

  • Root: use (Latin uti, meaning “to use”) → 与使用、应用相关
  • Suffix: -age 表示“行为或结果”
  • Formation: use + -age → usage
  • Related Words:
    • user — 用户
    • useful — 有用的
    • reuse — 再使用

derived /dɪˈraɪvd/

v — to come from a source or origin; to obtain something from a particular source
中文释义: 源自；衍生；得到。

Examples:

  • The word “salary” is derived from Latin.
  • Many modern technologies are derived from earlier inventions.

Common Phrases

  • derive from — 来自；源自
    • This custom is derived from ancient traditions.
  • be derived from — 起源于
    • The concept is derived from classical physics.
  • derive benefit — 获益
    • Students derive great benefit from practice.

Synonyms

  • originate
  • stem
  • obtain

Word Root

  • Root: riv- (Latin rivus, meaning “stream”) → 比喻“来源、流向”
  • Prefix: de- 表示“从、来源”
  • Formation: de + rive + -d → derived
  • Related Words:
    • derivation — 衍生
    • derive — 得到
    • river — 河流（比喻流向）
