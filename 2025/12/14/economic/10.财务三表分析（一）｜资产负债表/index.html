10.财务三表分析（一）｜资产负债表-中级

本文字数： 2.5k 阅读时长 ≈ 2 分钟
如何通过“公司财务运作逻辑 + 财务三表”，判断公司真实经营质量与风险。

财务三表分析（一）｜资产负债表

本期核心结论一句话：
财报不是用来“选公司”的，而是用来“排除垃圾公司”的。

一、承上启下：为什么要学财务三表

前两期我们已经做了两件事：

1️⃣ 讲清楚了公司是怎么做生意的（业务）
2️⃣ 讲清楚了财务是如何把业务记录成凭证，并最终汇总成财务三表

这一期开始，正式进入：

如何解读上市公司的财务三表

在正式讲技术之前，先回答几个大家最常问、但经常被严重误解的问题。

二、关于财报作假的三个核心问题

问题一：你怎么看财报作假？

结论先行：

财报作假不是股市问题，而是商业世界的常态风险。

1️⃣ 小公司 vs 上市公司

  • 私人小公司：
    • 除了税务，几乎没有监管
    • 财务数据改动空间极大
  • 上市公司：
    • 证监会监管
    • 审计师审计
    • 信息披露强制且高频

A 股 5400 多家公司：

  • 一定有造假的
  • 但绝大多数公司财报是真实的

2️⃣ 谁更容易造假？

业务烂的公司，才有强烈的造假动机。

  • 业务优秀 → 不需要造假
  • 业务稀烂 → 只能靠造假遮羞

📌 结论：

先从业务层面排除垃圾公司，本身就能极大降低踩雷概率。

问题二：普通投资者能靠财报识别造假吗？

结论很残酷：

仅靠财报数据，普通人几乎不可能识别造假。

原因有三：

1️⃣ 财报是谁做的？

  • CFO 牵头
  • 注册会计师审计
  • 年薪百万级专业团队

2️⃣ 现在不是“假数据”，而是“假业务”

  • 不是随便改个数字
  • 而是：
    • 先做一个假业务
    • 再把数据如实记账

📌 经典手法：

  • 操控渠道商高价进货
  • 虚增收入与利润

3️⃣ 监管不是吃干饭的

  • 直接改数字，很容易被查

与其说是财务造假，不如说是 业务造假。

典型案例：业务与财务“违和感”

1️⃣ 乐视网

  • 行业：在线视频
  • 同行业全亏损
  • 乐视却盈利

📌 疑点：

你不是行业龙头，凭什么赚钱？

最终 → 证监会调查 → 问题暴露

2️⃣ 瑞幸咖啡

  • 买一送一还能盈利？
  • 浑水实地调查：
    • 92 名全职
    • 1400+ 兼职
    • 蹲点 981 家门店

📌 发现：

  • 订单量虚增 70%+
  • 小票金额 > 实际支付金额

最终证明：财务没骗人，业务本身是假的。

问题三：为什么很多财务人员炒股也亏钱？

财务人员 ≠ 财务能力

  • 月薪 3000 的记账会计
  • vs
  • 年薪百万的 CFO

差距巨大

很多“财务人员”：

  • 只会做凭证
  • 报销、发工资、报税

📌 本质更像行政，而不是经营管理者

一个被反复误解的结论

股票投资的核心能力 = 企业经营能力

  • 财务能力：
    • 必要条件
    • 非充分条件

📌 推论：

  • 懂财务 ≠ 一定赚钱
  • 不懂财务 → 几乎不可能稳定赚钱

这也解释了：

  • 经济学家炒股亏
  • 金融专家炒股亏

对口职业是：企业家、创业者，而不是学者。

三、财报发布节奏 & 获取渠道

1️⃣ 财报发布时间

报告 发布时间
年报 年度结束后 4 个月内
半年报 2 个月内
一季报 1 个月内
三季报 1 个月内

📌 实际节奏：

  • 4 月：年报 + 一季报
  • 8 月：半年报
  • 10 月 31 日前：三季报

年报信息最全，业务披露最多。

2️⃣ 去哪里看财报？

巨潮资讯网（官方）

  • 所有上市公司公告
  • 财报、临时公告、重大事项

📌 职业投资者必会网站

四、年报结构速览（只看有用的）

  • 第二、三章：业务描述（重点）
  • 第七章：股权结构（首次看，后续略）
  • 第十章：财务三表

📌 原则：

只关注“变化的部分”，其余快速略过。

五、审计意见：第一道生死线

审计意见共五种：

只有一种能看：标准无保留意见

  • 不是这个意见 →
  • 财报一律视为假数据 → 公司直接淘汰

六、为什么先看资产负债表？

财务三表顺序本身就代表重要性：

1️⃣ 资产负债表（最重要）
2️⃣ 损益表
3️⃣ 现金流量表

📌 原因：

  • 损益表 = 结果
  • 资产负债表 = 过程

高手先看结构，新手先看利润。

七、资产负债表（资产端）核心拆解

分析思路：项目含义 → 业务场景 → 风险判断

（一）流动资产（经营类资产）

1️⃣ 货币资金

  • 看“荷包里有多少钱”
  • 没钱的公司 → 盈利能力大概率不行

📌 珀莱雅案例：

  • 货币资金 40+ 亿
  • 主要为银行存款
  • 说明：
    • 国内市场为主
    • 现金实力强

现金不一定代表赚钱，但没现金一定有问题。

2️⃣ 应收账款 / 应收票据

  • 本质：
    • 货交了
    • 钱还没收

📌 业务含义：

  • 产品抢手 → 先收钱
  • 产品一般 → 客户赊账

📌 风险：

  • 坏账

珀莱雅：

  • 约 5 亿坏账（历史纠纷）
  • 与 100 亿规模相比 → 可承受

应收高 + 坏账高 → 直接淘汰。

3️⃣ 预付账款

  • 提前支付给供应商的钱
  • 一般金额不大

珀莱雅：

  • 主要给阿里、京东、抖音
  • 合理、匹配业务

4️⃣ 其他应收款

  • 大杂烩项目
  • 与主营无关

📌 警惕信号：

现金少 + 其他应收款大 = 财务异常

珀莱雅：

  • 900 万
  • 可忽略

5️⃣ 存货

  • 未卖出的商品
  • 必须和收入规模对比

📌 看趋势：

  • 升高 → 销售不畅
  • 过低 → 缺货

📌 风险：

  • 存货减值
  • 虚增利润

（二）非流动资产

1️⃣ 长期股权投资

  • 投资上下游
  • 强化产业协同

📌 普通投资者：

知道是什么即可，不必深挖

2️⃣ 固定资产 & 在建工程

  • 判断：
    • 轻资产 / 重资产

📌 小细节：

  • 折旧完成仍在使用 → 后期利润更好看

3️⃣ 无形资产

  • 专利、商标、软件、土地使用权
  • 核心：业务合理性

懂财务 ≠ 能判断合理性，懂业务才行。

4️⃣ 商誉

  • 并购溢价形成

📌 观点：

  • 商誉是“过去的事”
  • 当前估值主要看现在和未来

📌 风险点：

  • 高价并购
  • 利益输送

5️⃣ 长期待摊费用

  • 已花钱
  • 未来计入成本

📌 原则：

金额大且不合理 → 直接淘汰

6️⃣ 递延所得税资产

  • 会计口径 ≠ 税务口径
  • 多交的税 → 记资产

📌 特点：

  • 税务科目
  • 与经营关系不大

八、图形化：让资产结构一眼看懂

📌 方法：

  • Excel
  • 合并同类项
  • 做柱状图

数字看不懂，就看结构。

珀莱雅：

  • 现金高
  • 应收低
  • 结构健康

垃圾公司：

  • 应收占比极高
  • 现金枯竭

资产结构，直接决定公司生死。

九、负债端分析（更真实的一侧）

财务造假多在资产端，负债端反而更真实。

1️⃣ 短期借款

  • 没钱才借钱
  • 好公司一般现金充足

珀莱雅：

  • 无短期借款

2️⃣ 应付账款（经营性负债）

  • 拿货不立刻给钱
  • 本质是无息融资

📌 特征：

  • 高 → 供应链强势
  • 过高 → 压榨供应商

3️⃣ 合同负债 / 预收账款

  • 先收钱
  • 后发货

📌 案例：

  • 茅台：合同负债极高
  • 房地产：期房销售

4️⃣ 有息负债（真正的风险）

  • 短期借款
  • 长期借款
  • 应付债券

📌 核心逻辑：

增长能否覆盖债务？

借贷是杠杆，用不好就是深渊。

十、典型公司资产结构对比

  • 茅台：
    • 现金爆表
    • 几乎零有息负债
  • 比亚迪：
    • 固定资产高
    • 应付账款高（供应链强势）
  • 长江电力：
    • 重资产
    • 高分红
  • 科大讯飞 / 常山北明：
    • 应收高
    • 回款差
    • 现金覆盖不了债务
  • 东方集团：
    • 现金 46 亿
    • 短期债务 169 亿
    • 造假情况下仍亏损

这种公司，多看一眼都是浪费时间。

十一、总结

  • 资产负债表 = 企业体检报告
  • 结构比利润重要
  • 财报是排除工具，不是选股工具

看完资产负债表，大多数垃圾公司已经被你淘汰掉了。
