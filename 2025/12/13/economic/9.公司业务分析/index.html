9.公司业务分析-中级

公司业务分析，金融的本质就是对风险进行定价

公司业务分析

核心思想一句话：
如果你连一家公司是做什么的都搞不清楚，就去买它的股票，本质上是在赌博。

一、分析陌生公司的第一步：信息从哪里来（解决信息差）

普通投资者最大的问题不是不会分析，而是信息差。分析业务前，必须先搞清楚信息来源。

1️⃣ 公司官方披露信息（最重要）

上市公司公告是第一信息源，权重最高。

  • 定期报告（核心）
    • 年报（最完整，信息披露要求最高）
    • 半年报
    • 一季报、三季报（主要披露财务数据）
    • A 股公司一年 4 次财报
  • 月度业务报告（部分行业常见）
    • 房地产：销售面积、成交均价
    • 可用于高频跟踪业务变化
  • 临时性公告
    • 签大单
    • 重大项目进展
    • 技术突破、政策事项等

📌 结论：

财报 = 公司自己给你的“标准答案”，必须长期、反复看。

2️⃣ 公司官网 & 新媒体平台

  • 官网通常是 营销展示平台
  • 产品信息最全、最直观
  • 可快速梳理：
    • 产品种类
    • 产品定位
    • 应用场景

📌 用途：

用来梳理公司的 产品矩阵。

3️⃣ 行业数据（自上而下）

每家公司都属于某个行业，先看行业，再看公司。

  • 大行业通常有权威统计机构
    • 汽车：汽车工业协会（销量、出口）
    • 地产：官方销售数据

📌 好处：

行业数据先行 → 公司数据验证 → 结论更客观。

4️⃣ 线下市场调研（最接地气）

  • 消费品：
    • 门店体验
    • 实际购买
  • 汽车：
    • 4S 店直接问销售

📌 限制：

  • B 端产品（企业服务）普通投资者很难调研
  • 除非你本身是行业从业者

5️⃣ 人脉咨询 & 付费咨询

  • 问朋友（上市公司员工 / 行业从业者）
  • 猎头付费咨询：
    • 对接中高层
    • 适合重仓前使用

📌 总结信息来源四大类：

  1. 公司公告
  2. 官网 / 新媒体
  3. 行业数据
  4. 调研（线下 + 人脉）

二、业务分析的核心切入口：产品

产品是一切分析的起点。

❗ 投资铁律

接触不到产品和服务的公司，普通投资者最好不要投。

原因：

  • 无法判断产品竞争力
  • 只能凭感觉、赌运气

1️⃣ 可投公司的数量其实非常多

  • 能接触到的头部公司就有 500+
  • 精选后 200 家 已完全够用

示例（部分）：

  • 白酒：茅台、五粮液、泸州老窖
  • 家电：美的、格力、海尔
  • 汽车：比亚迪、小米、宁德时代
  • 食品饮料：伊利、海天
  • 电商 / 游戏：阿里、腾讯、网易
  • 交通：京沪高铁、上海机场

📌 结论：

不需要碰你完全不懂、也用不到的公司。

三、产品矩阵分析（公司业务结构）

1️⃣ 什么是产品矩阵

大公司几乎都不是单一产品，而是矩阵式布局。

2️⃣ 健康的产品矩阵 = 四类产品

类型 作用
核心产品 当前业绩支柱
战略产品 未来增长
辅助产品 提升体验、增强粘性
淘汰产品 主动退出落后需求

📌 比亚迪案例

  • 核心：秦 / 宋 / 汉 / 唐
  • 战略：仰望（冲高端）
  • 辅助：电池服务、车险、售后
  • 淘汰：燃油车（2022 年全面停产）

👉 持续推出新产品 + 淘汰旧产品 = 企业在进化

3️⃣ 产品覆盖分析

  • 横向覆盖：
    • 轿车 / SUV / MPV / 越野 / 跑车
  • 纵向覆盖（价格带）：
    • 高端 / 中端 / 低端

4️⃣ 产品集中度风险

  • 依赖单一产品 = 抗风险能力差

案例：

  • 长城：过度集中越野
  • 理想：过度依赖 L 系列

📌 新公司早期可接受，但需持续观察。

四、产品力分析 = 竞争优势分析

投资视角下的三大维度

1️⃣ 成本优势

  • 比亚迪
  • 小米

2️⃣ 技术领先

  • 大疆无人机

3️⃣ 品牌溢价

  • 奢侈品
  • 苹果

📌 本质问题：

同价位下，你凭什么选它？

定价权（最重要）

  • 不是“想卖多贵卖多贵”
  • 而是：
    • 行业定价锚

案例：

  • 苹果手机
  • 华为折叠屏（突破苹果定价权）

📌 判断方法：

消费者在某个价位，会不会“必须先考虑你”。

产品力验证方式

  • 市占率
  • 销量数据
  • 用户口碑（论坛 / 朋友）

市场反馈是最真实的答案。

五、产品层面的主要风险

1️⃣ 收入是否过度集中在单一产品
2️⃣ 产品优势是否可持续
3️⃣ 政策风险（新能源补贴、集采等）

六、市场与销售分析（把产品卖出去）

1️⃣ 市场分析

  • 国内 vs 海外
  • 重点关注：
    • 贸易战
    • 地缘政治

2️⃣ 销售模式

模式 特点 案例
直销 利润高、成本高 苹果官网、特斯拉
分销 覆盖广 食品、医药
电商 新渠道 自营 / 分销

3️⃣ 销售策略

  • 解决方案式（ERP）
  • 顾问式（高端医疗）
  • 关系型（政府 / 国企）

📌 上市公司一般不会犯低级错误，重点看趋势。

4️⃣ 投资视角的销售分析三点

1️⃣ 销售动作 → 判断业绩增速
2️⃣ 渠道调研 → 提前获取销售信息
3️⃣ 营销效率 → 费用 / 收入比

企业竞争的本质是效率竞争。

5️⃣ 销售端风险

  • 渠道冲突（线上 vs 线下）
  • 经销商流失
  • 库存积压

📌 现象级信号：

4S 店关店、销售转卖其他品牌。

七、生产制造分析（成本与效率）

1️⃣ 生产模式

模式 特点 风险
自建工厂 品控强 成本刚性
代工 轻资产 供应链依赖
混合 平衡 管理复杂

2️⃣ 成本构成

  • 原材料
  • 人工
  • 制造费用

重点关注：

  • 原材料价格波动（如锂矿）

3️⃣ 规模效应

  • 销量越大 → 单位成本越低
  • 比亚迪的成本优势来源之一

4️⃣ 制造效率分析

  • 技术工艺领先
  • 自动化水平
  • 资产周转率（杜邦分析）

📌 必须做：

  • 同行业横向对比
  • 自身历史纵向对比

5️⃣ 制造端风险

1️⃣ 产能过剩
2️⃣ 技术落后
3️⃣ 外包依赖（被卡脖子）

八、终极总结（分析逻辑闭环）

业务分析三大环节

1️⃣ 产品：看竞争力，（尽量不买接触不到产品的工资）
2️⃣ 销售：看效率
3️⃣ 制造：看成本与效率

核心思想

  • 所有分析最终都是：
    • 风险识别
    • 风险定价

金融的本质：为风险定价。

  • 公司质量 ≠ 是否值得买
  • 中间还隔着一个：价格是否合适

📌 最优策略：

盯着优质公司 → 等合适价格 → 再出手。

结语

  • 中级内容难度高
  • 需要商业 + 财务基础
  • 学不会也没关系

至少知道：正确的方法是什么，少走弯路。
