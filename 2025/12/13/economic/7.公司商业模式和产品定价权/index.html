7.公司商业模式和产品定价权-中级

从初创公司到IPO，公司股权变化

商业模式：优质公司的第一道筛选器

一、为什么商业模式是基本面分析中最重要的内容？

1️⃣ 决定投资“能不能长期赚钱”

  • 方法论是否正确 → 决定能否长期存活
  • 对商业模式理解的深度 → 决定收益率天花板

同样的方法，有的人只能跑赢一点点，
有的人能长期获得远超市场的回报，
本质差异就在于：商业模式理解能力。

2️⃣ 中级课程的核心任务

  • 初级课程：正确认识股票
  • 中级课程：学会如何做投资决策

股票投资的标准三步流程：

👉 本节课解决 第①步：如何筛选优质公司

二、公司三大分类：垃圾 / 平庸 / 优秀

1️⃣ 垃圾公司（必须回避）

特征：

  • 产品或服务已被市场淘汰
  • 业绩持续恶化
  • 常年亏损
  • 退市风险极高

投资结果：

  • 只能博短期投机
  • 一旦退市 ≈ 本金归零

📌 现实提醒：

  • 近 3 年，每年约 40+ 公司退市
  • 编号缺失的股票 = 已从市场消失

⚠️ 现在的退市制度，不再给“补仓自救”的机会。

2️⃣ 平庸公司（数量最多）

占比：

  • A 股中 80% 以上

特征：

  • 位于行业中下游或供应链
  • 无定价权
  • 赚辛苦钱
  • 盈利依赖行业整体景气

投资结果：

  • 操作好 → 接近社会平均回报
  • 操作差 → 长期持有也赚不到什么
  • 容错率极低

3️⃣ 优质公司（重点研究对象）

特征：

  • 行业龙头
  • 产品或服务具有 定价权
  • 能赚取品牌溢价 / 技术溢价

投资关键：

  • 估值是否合理
  • 是否处于行业 / 经济下行周期

长期结果：

  • 胜率高
  • 收益率显著高于市场平均

三、什么是商业模式？（最通俗的定义）

商业模式 = 企业赚钱的方式

不是高深概念，而是一个非常生活化的问题：

“这家公司，是怎么赚钱的？累不累？可不可以复制？有没有上限？”

四、从个人赚钱方式理解商业模式

1️⃣ 劳务性收入（出售时间）

  • 上班族 / 体力或脑力劳动
  • 收入被时间锁死
  • 时间成本极高

📌 特点：
稳定但天花板极低

2️⃣ 产品性收入（出售产品）

  • 写书、自媒体、课程、软件
  • 一次创作，可无限复制
  • 突破时间限制

📌 特点：
可扩展、非线性增长

3️⃣ 资产性收入（出租资产）

  • 房租
  • 股权分红
  • 利息收入

📌 特点：
最轻松、但需要前期积累

👉 公司也是人组成的
公司商业模式，本质上与人的赚钱方式完全一致。

五、公司商业模式三大类型（金字塔结构）

金字塔越往上，
商业模式越轻松、越可复制、越有天花板。

六、服务型公司：规模受限的生意

1️⃣ 核心特点

  • 强依赖人
  • 难以标准化
  • 扩张成本高
  • 管理难度极大

2️⃣ 餐饮案例

  • 普通中餐馆：
    • 依赖厨师
    • 难以复制
  • 火锅（海底捞）：
    • 去厨师化
    • 食材标准化
    • → 产品型公司

3️⃣ 家装行业案例

  • 家装公司：
    • 典型服务型
    • 难标准化
    • 极难做大
  • 家居建材公司（兔宝宝 / 老板电器）：
    • 产品化
    • 易规模扩张
    • 更容易上市

4️⃣ 黄金首饰的“伪产品型”

  • 黄金成本高度透明
  • 赚的是加工费
  • 本质：服务型生意

📌 结果：

  • 金价涨 → 收入涨
  • 利润不涨
  • 现金流压力反而变大

5️⃣ 服务型公司的天花板

  • 顺丰：（净资产收益率只有百分之10）
    • 收入巨大
    • 利润率低
    • 扩张成本极高

商业模式不是“差”，
而是 “又苦又累，回报不高”

📌 投资原则：

非极低估值，不关注服务型公司

七、产品型公司：看“定价权”

1️⃣ 核心判断标准

产品是否具备定价权

定价权不是：

  • 想卖多贵就卖多贵

而是：

  • 竞争对手定价要参考你

2️⃣ 茅台案例

  • 飞天茅台：
    • 无竞品
    • 几乎无更新压力
    • 产品力跨越十年以上

📌 极少数“反时间”的产品型公司

3️⃣ 产品更新压力

  • 汽车行业：
    • 合资车因不思进取而衰落
  • 科技行业：
    • 苹果也曾因产品失败差点消失

📌 绝大多数产品型公司：

  • 必须持续创新
  • 否则迅速被淘汰

4️⃣ 定价权的现实例子

  • 手机：苹果
  • 折叠屏：华为
  • 电动车：特斯拉 Model 3（正在被挑战）

📌 投资原则：

只考虑产品具备定价权的公司

八、平台型公司：最好的商业模式

1️⃣ 平台的本质

  • 把平台 租给别人用
  • 躺着收租

2️⃣ 苹果的真正核心

  • 对消费者：产品公司
  • 对开发者：平台公司
  • App Store：
    • 高利润
    • 轻资产
    • 抽成模式

3️⃣ 典型平台公司

  • 电商平台：阿里 / 京东
  • 流量平台：腾讯 / 字节
  • 银行：资金租赁
  • 基础设施：
    • 上海机场（商铺租赁）
    • 长江电力（发电能力租赁）

📌 特点：

  • 轻松
  • 稳定
  • 可持续
  • 天花板极高

九、投资中的最终筛选原则

标准流程

个人投资偏好总结

只重点关注两类公司：

1️⃣ 产品具备定价权的产品型公司
2️⃣ 以“租”为核心的平台型公司

不优先考虑

  • 服务型公司
  • 无定价权的产品公司
    （除非估值极低）

十、核心结论（一句话）

商业模式决定公司“能不能轻松赚钱”，
估值决定你“赚不赚钱”。

当你只关注商业模式优秀的公司时：

  • 可选公司 < 200 家
  • 投资复杂度大幅下降
  • 长期胜率显著提高
