3.常见的投资品种-初级

发表于 2025-12-07 更新于 2025-12-13 分类于 经济 阅读次数：
本文字数： 1.7k 阅读时长 ≈ 2 分钟
投资学习必要性与货币本质

常见的投资品种

一、不可能三角：评估所有投资品种的底层框架

任何投资品种，都可以用三个维度来评估：

  • 流动性（Liquidity）：变现速度
  • 风险（Risk）：未来结果的不确定性
  • 预期收益（Return）：能获得多少回报

三者不可同时兼得。

示例：

  • 需要短期用钱 → 不选流动性差的资产
  • 承受不了本金损失 → 不碰高风险品种
  • 想要高收益 → 必然承担高风险

二、普通人能接触到的五大类投资品种

  1. 债券（Bond）
  2. 固定资产（Real Assets）：住房、商铺、写字楼
  3. 公司股权（Equity）：股票 & 私募股权
  4. 大宗商品（Commodities）
  5. 货币替代物（Monetary Substitutes）：黄金/外汇/比特币

其他常听到的产品（基金、期货、REITs…）本质都是对上述品种的不同交易形式或包装方式。

三、各投资品种详解

① 债券（Bond）

本质：借钱收利息

是最古老、规模最大的金融市场。

为什么债券价格会波动？

债券价格与市场利率是跷跷板关系：

  • 利率下降 → 旧债更值钱 → 债券价格上涨
  • 利率上升 → 旧债变便宜 → 债券价格下跌

例如：

  • 你持有 3% 利率债券
  • 市场新债只有 2%
  • 你的债券自然更值钱 → 可以溢价卖出

债券的“三角”定位

  • 流动性：高
  • 风险：低
  • 收益：低

适合机构或大量闲钱的管理。
普通人更多用：货币基金、国债逆回购。

垃圾债券（高风险高收益）

指公司财务恶化、偿债能力差导致价格暴跌的债券。
可能 30 块买到面值 100 的债券。

  • 赌公司能否活下来
  • 一旦违约 → 亏损100%

特殊玩法，不推荐普通人参与。

② 固定资产（住宅 / 商铺 / 写字楼）

（1）住宅

属性定位

  • 流动性：极差
  • 风险：低
  • 收益：中等（强周期影响）

为什么近年跌？因为：

  1. 经济周期（涨得太高 → 回落）
  2. 利率周期（全球加息 → 资产估值下降）
  3. 人口周期（核心矛盾）

人口周期决定住宅需求

关键逻辑：

  • 1986–1990：第二次婴儿潮（每年约2600万）
    → 2015–2021 正好进入购房年龄 → 房价大涨
  • 2021后：刚需见顶 → 房价下行

未来预测：

  • 新生人口 2003 见底 → 2003 年出生 → 2028 年进入购房年龄
    → 房价预计2028触底，之后可能迎来新一轮修复。

住宅建议

  • 二三线：当消费品，不要当投资
  • 一二线：看人口是否净流入
  • 核心指标：租售比、居住质量、生活便利度

（2）商铺 & 写字楼

为什么现在普遍不行？

  • 线上零售替代线下零售
  • 疫情加速线下衰退
  • 写字楼空置率上升

一些上市百货公司（天鸿、武商）在疫情后业绩至今未恢复，说明行业发生结构性变化，而非短期冲击。

三角定位

  • 流动性：很差
  • 风险：中等
  • 收益：一般

适合自用，不适合投资。

（3）REITs（睿资）

本质：把写字楼、园区、高速公路等固定资产拆成“小份额”销售。

优点：

  • 流动性大幅提高
  • 参与门槛极低（几百元）

缺点：

  • 波动比传统固定资产高，风险增加

总体定位：流动性高 + 风险提高 + 收益中等

③ 公司股权（Equity）

分两类：

  • 一级市场（未上市公司）：没流动性，专属机构
  • 二级市场（股票）：普通投资者主要接触领域

知识点：

  • IPO 申购买的是“一手货”
  • 股票市场交易的是其他人卖出的“二手股权” → 所以叫二级市场

（股票部分将在后面章节重点讲）

④ 大宗商品（Commodities）

包括：

  • 原油
  • 铁矿石
  • 铜
  • 农产品

它们大多数以期货方式交易。

注意一个常见误区：

大宗商品不是期货，期货只是交易形式。

例如：
铜 ≠ 期货
“铜期货”才是交易工具。

⑤ 货币替代物：黄金 / 外汇 / 比特币

这类资产本质上是：

  • 抵御货币贬值
  • 规避系统性风险

不属于能持续产生收益的资产，更像一种价值存储工具。

四、总结：投资品种的底层本质

投资品种 流动性 风险 预期收益 特点
债券 高 低 低 本质借钱收利息；利率倒挂与价格关联强
住宅 很低 低 中等 强受人口周期影响；一二线与三四线差别极大
商铺写字楼 很低 中 一般 行业结构性衰退；适合自用
REITs 高 中~高 中 固定资产证券化，波动增大
股票 高 中~高 中~高 未来章节重点讲
大宗商品 高（期货） 高 高 更多是交易型而非投资型
黄金/外汇/比特币 高 中 不稳定 价值储存，不产生现金流

一句话底层结论

所有投资本质上都是在流动性、风险、收益之间做取舍，
选适合自己财务状况与风险承受能力的品种才是关键。
