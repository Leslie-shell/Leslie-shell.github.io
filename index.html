一、jstack

jstack 用于打印 Java 进程中 所有线程的执行栈和状态，是线上排查 CPU 飙高、卡死、死锁问题的核心工具。

典型用途：

  • CPU 使用率异常
  • 接口无响应 / 系统假死
  • 线程池耗尽
  • synchronized / Lock 死锁
